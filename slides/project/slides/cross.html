Four ants, four directions

up · right · down · left

split · half up, half down, same cell

Left: four ants, all running the gecko brain, each started ten cells out from the centre along its own heading, one facing each cardinal direction. Each paints its gecko relative to its own start and heading, so the four geckos sit in a pinwheel, each rotated by ninety degrees, touching in the middle. Right, the split experiment: ten ants on the same cell, five facing up and five facing down, so one gecko the right way up and one upside down land on top of each other around the same origin. 10 000 steps; the red squares are the ants, slow at first, then sped up and faded.
