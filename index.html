    How it works

    one ant, one step, six thousand times over

    1. 01

      Reads

      Gradients across the 3×3 patch under it, turned into the frame it faces. It sees nothing further, ever.

    2. 02

      Thinks

      Those, and how far it has walked from where it woke up, through one network of 14,483 numbers.

    3. 03

      Writes and turns

      A delta into the cell below, then a turn sampled from three: left, straight on, or right. Then it steps.

    Carries
    A position and a heading, and nothing else.
    Frame
    Egocentric. Rotate the ant and the drawing turns with it.
    A cell
    Sixteen numbers: three the picture, thirteen scratch.
    Crowd
    One brain runs them all, whether one ant or nine.
    Learned
    Backprop for painting, trial and error for walking.
    Repair
    Never trained. Damage was never shown to it, yet cut a piece away and the colony puts it back.

    Train your own

    a couple of hours on a gpu

    # clone and install
git clone https://github.com/ichko/nants
cd nants && uv sync

# pick an emoji at the top, then leave it running
uv run python starter/my_nants.py

# one to nine ants a colony, damaged halfway
uv run nants-crowd out/<datetime>

    It writes a folder under out/ you can watch while it works: the picture as it stands, the error curve, and the best brain so far.

    Stop it whenever you like. The good one is already on disk, and pointing the trainer back at the same folder carries on from there.
