Ants do dead reckoning

Ronacher, B. (2008). Path integration as the basic navigation mechanism of the desert ant Cataglyphis fortis (Forel, 1902). Myrmecological News 11: 53–62.

The page is the first page of Bernhard Ronacher's 2008 review in Myrmecological News, an open-access journal. The highlighted sentences of the abstract are the claim in one breath: Cataglyphis ants forage up to a hundred thousand body lengths from the nest and return to it with high precision using path integration, that is dead reckoning, as their main navigational aid. The review goes on to the stride integrator, the sky compass, and the finding that path integration keeps working over hills because the ants correct for slope. The classic primary paper is Müller and Wehner 1988 in PNAS, Path integration in desert ants, Cataglyphis fortis, which showed the integration is an approximation with small systematic errors.
