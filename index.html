Inside the cells

channels 3–15 · the ants' own scratch space

    How it works

    one ant, one step, six thousand times

    What it carries
    A position and a heading. Nothing else survives a step.
    What it sees
    Its own 3×3 patch, rotated into the frame it faces.
    What a cell holds
    Sixteen numbers. Three are the picture, thirteen are scratch.
    How it turns
    Sampled from three, so no two runs come out alike.
    How many brains
    One. The same 14,483 numbers run every ant in the colony.
    How it learned
    Backprop for the painting, trial and error for the walking.

    Train your own

    a couple of hours on a gpu

    # clone and install
git clone https://github.com/ichko/nants
cd nants && uv sync

# pick an emoji at the top, then leave it running
uv run python starter/my_nants.py

# one to nine ants a colony, damaged halfway
uv run nants-crowd out/<datetime>

    It writes a folder under out/ you can watch while it works: the picture as it stands, the error curve, and the best brain so far.

    Stop it whenever you like — the good one is already on disk, and pointing the trainer back at the same folder carries on where it left off.
