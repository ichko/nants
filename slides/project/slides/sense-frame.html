How does the ant perceive

We orient two sobel filters with the direction of the ant. The same setup you have in Neural Cellular Automata (NCA) perception.

heading up
The field stays put and the ant walks about in it, turning and stepping, never leaving the grid. The kernel is fixed to the ant, so the same weight always reads the cell ahead, or the cell aside. That is why a trained colony draws the same animal in any of the four poses.
