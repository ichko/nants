NAnts are to Langton's ant what NCAs are to cellular automata: the rule is learned rather than written by hand.

The field

step 0 ants 0

Controls

pointer

Erase part of the drawing and the colony repairs it. Add ants somewhere else and they start a second one.

Inside every cell

3 channels are the picture · 13 are the colony's memory

    What one ant does, every step

    1. Look

      The ant reads the 3×3 cells around it and measures how the values change across them. The measurements are rotated to match the way it is facing.

    2. Add its own position

      It also knows how far it has walked from the cell it started on. It has no other sense of where it is.

    3. Run the network

      Those 93 numbers go through one small network of 14,483 weights, which returns 19 numbers.

    4. Write and turn

      16 of them are added to the cell underneath. The other 3 pick a turn — left, straight, or right — and the ant steps forward.

    Repeat six thousand times and a gecko is on the grid.

    Worth knowing

    Repair was never trained
    The colony was only ever shown a blank grid. Nobody taught it to fix damage, yet erase part of the drawing and it fills the gap back in.
    No memory
    An ant keeps a position and a heading between steps, and nothing else. Every decision starts over.
    No talking
    Ants never signal one another. They share a grid, and that is the only thing that connects them.
    One network, any number of ants
    The same 14,483 weights run every ant. One ant draws the gecko slowly; nine draw it quickly.
    Everything is relative
    What an ant senses is measured from the way it faces, so turning it at the start turns the whole drawing.
    Two kinds of learning
    Backprop teaches it what to write. The turns are discrete, so those are learned by trial and error instead.

    Train your own

    Pick any emoji and grow that instead. A run takes a couple of hours on a gpu, and you can watch the picture improve while it goes.

    It writes a folder under out/ holding the drawing as it stands, the error curve, and the best network so far. Stop it whenever you like — the best one is already saved.
