    How it works

    • No memory. An ant carries nothing from one step to the next. Every decision is made from scratch.
    • No map. It only knows how far it has walked from its own starting cell, the way an ant counts its steps home.
    • No talking. Ants never signal each other. They share a field, and that is all.
    • One brain, any crowd. The same 14,483 numbers run every ant. One ant paints the gecko slowly; nine paint it quickly.
    • Trained, not designed. What to paint is learned by ordinary backprop. Where to walk is learned by trial and error, since a turn cannot be differentiated.

    Train your own

    Pick a different emoji and grow that instead. A run takes a couple of hours on a gpu, and you can watch it improve while it goes. 

    git clone https://github.com/ichko/nants
cd nants
uv sync

uv run nants-train                     # writes out/<datetime>/
uv run nants-crowd out/<datetime>      # renders the gif

    To grow something else, copy starter/my_nants.py, change the emoji at the top, and run it. Everything else is already wired up.
