    How it works

    one ant, one step

    1. 1

      It looks

      At its 3×3 patch. Nothing further, ever.

    2. 2

      It decides

      One small network. 93 numbers in, 19 out.

    3. 3

      It paints

      Adds to the cell below, then turns.

    4. 4

      It walks on

      Six thousand times. A gecko appears.

    It knows two more things: how far it has walked from where it woke up, and how far through the run it is. That is the whole of its world.

    • No memory. Nothing carries from one step to the next.
    • No map. Only the distance walked from its own starting cell.
    • No talking. Ants share a field, and nothing else.
    • One brain, any crowd. The same 14,483 numbers run every ant.
    • Learned, not written. Backprop for the painting, trial and error for the walking.

    Train your own

    a couple of hours on a gpu

    # get it
git clone https://github.com/ichko/nants
cd nants && uv sync

# change the emoji at the top of the file, then grow it
uv run python starter/my_nants.py

# see what it made
uv run nants-crowd out/<datetime>

    It writes a folder under out/ you can watch while it works — the picture as it stands, the error curve, and the best brain so far. Stop it whenever you like; the good one is already saved.
